# TravelBot - Codingal Chatbot Activity

An interactive travel assistant chatbot built in Python featuring Colorama for styled terminal outputs.

## Features
- **Travel Recommendations**: Suggests destinations based on preferences (beaches, mountains, cities).
- **Packing Tips**: Provides advice depending on destination and trip duration.
- **Jokes**: Tells travel and tech-related jokes.
- **Simulated Weather**: Reports weather conditions for popular cities.
- **Travel News**: Delivers helpful travel tips and updates.
- **Local Time**: Displays real-time local time across various time zones using `zoneinfo`.

## Installation & Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/sidharthdhimanbeep/Codingal-Chatbot-Activity.git
   cd Codingal-Chatbot-Activity
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the chatbot:
   ```bash
   python main.py
   ```
